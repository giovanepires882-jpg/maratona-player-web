# Maratona Player · site de listas

Site onde a pessoa adiciona as próprias listas (link M3U ou Xtream) ao aparelho com o Maratona Player, usando o ID do aparelho e a chave que aparecem na tela.

**Este app não fornece conteúdo.** Ele só reproduz as listas que o próprio usuário adiciona.

- `index.html`: o site (HTML e JS puro, sem dependências externas).
- `config.js`: endereço do Supabase e chave pública (anon).
- Teste sem servidor: abra `index.html?demo=1`.
