# Maratona Player · painel

Painel onde a pessoa cria conta (e-mail e senha), cadastra os dispositivos (MAC e key da TV) e envia listas M3U ou Xtream.
Cada MAC ganha 24 h de teste uma vez; depois, licença por aparelho (diária, mensal, semestral ou anual) paga por Pix ou cartão (Mercado Pago).

**Este app não fornece conteúdo.** Ele só reproduz as listas enviadas pelo painel.

- `index.html`: o painel (HTML e JS puro).
- `config.js`: endereço do Supabase e chave pública (anon).
